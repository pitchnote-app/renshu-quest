# 公開手順（かんたん版）

家族やチームに試してもらうための「試験公開」の手順です。どれも**無料**でできます。
公開用のファイルは `python tools/build.py` で作られる **`dist/` フォルダ**です。

---

## おすすめ①：Netlify Drop（いちばん簡単・5分）
1. https://app.netlify.com/drop をブラウザで開く
2. 無料アカウントを作る（メールアドレスかGoogleアカウント）
3. `dist` フォルダを画面にドラッグ＆ドロップ
4. `https://（ランダムな名前）.netlify.app` というURLが発行される → スマホで開いて「ホーム画面に追加」
5. 名前は「Site configuration」→「Change site name」で `renshu-quest` などに変更できる

更新するとき：`python tools/build.py` → 「Deploys」タブに `dist` をもう一度ドロップ

## おすすめ②：GitHub Pages（コードの管理もまとめてできる）
1. https://github.com で無料アカウントを作る
2. 新しいリポジトリを作る（例：`renshu-quest`）
   - 無料プランで Pages を使うにはリポジトリを **Public（公開）** にする必要がある
3. **注意：公開リポジトリにすると、コミットのメールアドレスも公開される。**
   GitHub の「Settings → Emails」で表示される `xxxx@users.noreply.github.com` を使うのがおすすめ。
   → このアドレスを教えてもらえれば、既存の記録の作成者情報を置きかえてから公開できます。
4. このフォルダをアップロード（または `git push`）
5. リポジトリの「Settings → Pages」で公開元を設定する
   - 簡単にするなら `dist` の中身だけを別のリポジトリにアップロードして、ブランチ `main` の `/ (root)` を指定
6. `https://（ユーザー名）.github.io/renshu-quest/` で公開される

---

## 公開前チェックリスト
- [ ] `node tools/test_logic.js` がすべて成功
- [ ] `python tools/build.py` で `dist/` を作り直した
- [ ] スマホで開いて、キャラ作成 → 練習の記録 → レベルアップまで動く
- [ ] 「ホーム画面に追加」してアイコンが表示される
- [ ] 機内モードにしても起動する（HTTPS で公開したあとに確認）
- [ ] プライバシーポリシー（`privacy.html`）が開ける

## 試験公開で集めたいこと
- 子どもが**自分から**開いたか（何日続いたか）
- どの画面で迷ったか・押し間違えたか
- 好きだった機能（宝箱？ カード？ ライバル？）
- 練習メニューの難しさ（★の付け方が合っているか）
- 保護者の感想（レポートは役に立ったか）
