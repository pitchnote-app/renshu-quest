# 共同編集の始め方（2人目の人向け）

れんしゅうクエストを、自分の Claude で一緒に直していくための準備です。所要時間は30分くらい。

## 1. GitHub のアカウントを作る（無料）
1. https://github.com/signup で登録
2. できたら、**ユーザー名**をオーナー（夫）に伝える → オーナーがリポジトリに招待します
3. 届いた招待メール（または https://github.com/pitchnote-app/renshu-quest/invitations ）で「Accept invitation」を押す

## 2. PC に必要なものを入れる
- **Claude デスクトップアプリ**（Code タブを使います）
- **Git**：https://git-scm.com/download/win （Windowsの場合。インストール時の設定はすべてそのままでOK）
- **Python**：https://www.python.org/downloads/ （「Add python.exe to PATH」にチェック）
- **Node.js**：https://nodejs.org/ （LTS版）

※ わからなければ、Claude に「れんしゅうクエストを編集する準備をしたい」と頼めば、手順を案内してくれます。

## 3. アプリのファイルを手元に持ってくる
Claude の Code タブで作業フォルダを決めて、Claude にこう頼む：

> https://github.com/pitchnote-app/renshu-quest を clone して、このフォルダで作業できるようにして

途中で GitHub のログイン画面が出たら、自分のアカウントでログインします。

## 4. Claude にお願いする
フォルダを開いた状態で、やりたいことをそのまま伝えればOK。例：
- 「練習メニューに『リフティングしながら歩く』を追加して」
- 「ボルトのセリフをもっと増やして」
- 「この画像（ChatGPTで作ったシート）を背景として取りこんで」

Claude はリポジトリの `CLAUDE.md`（作業ルール）を自動で読むので、夫の Claude と同じ方針で作業します。

## 5. 公開の流れ
1. Claude は作業用の「ブランチ」で変更して、**Pull Request（変更の提案）**を作ります
2. 相手（夫）が GitHub で中身を見て「Merge」を押すと、自動で公開ページに反映されます
   → https://pitchnote-app.github.io/renshu-quest/
3. 2人が同時に同じところを直すとぶつかることがあるので、**作業を始める前に「今からここを直すね」と声をかける**と安心です

## 困ったとき
- 「動かなくなった」「元に戻したい」→ Claude に「さっきの変更を取り消して」と頼む（記録はすべて残っているので、いつでも戻せます）
- 何をしたらいいか迷ったら → Claude に「README と docs を読んで、今どんな状態か教えて」と頼む
