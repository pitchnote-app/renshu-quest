# プライバシーポリシー（案）

> ※この文書は下書きです。公開前に、運営者名・連絡先・施行日を記入し、必要に応じて専門家の確認を受けてください。

**れんしゅうクエスト**（以下「本アプリ」）は、子どもたちが安心して使えることを最も大切にしています。

## 1. 収集する情報
本アプリは、**利用者の個人情報を収集しません。**
アプリ内で入力されたキャラクターの名前・年齢・練習の記録などは、**ご利用の端末の中だけに保存**され、運営者や第三者のサーバーに送信されることはありません。

## 2. 広告・解析ツール
本アプリには、**広告は表示されません。**また、利用状況を分析するための外部ツール（アクセス解析など）も使用していません。

## 3. 第三者への提供
前項のとおり情報を収集しないため、第三者に提供することはありません。

## 4. データの保存と削除
- 記録は端末内に保存されます。アプリの「せってい」→「最初からやり直す」から、いつでもすべてのデータを削除できます。
- 「バックアップを保存する」機能で作成したファイルは、利用者の端末に保存されます。取り扱いには注意してください。
- アプリを削除すると、端末内の記録も削除されます。

## 5. 保護者の方へ
データの削除・バックアップの保存や読みこみなど、大切な操作の前には、保護者の方の確認（簡単な計算問題）を表示しています。
