# 育成アプリ・RPGの「ハマる要素」調査と、れんしゅうクエストへの反映

調査日：2026年11月25日

## 1. 調べたこと（要点）

| 要素 | 代表例 | なぜハマるか | 注意点 |
|---|---|---|---|
| **連続記録（ストリーク）** | Duolingo | 「途切れさせたくない」という損失回避がいちばん強い継続の力になる | 途切れたときの挫折感が大きい。Duolingo 自身も「ストリークフリーズ（お守り）」で1日休んでも守れるようにしている |
| **ランダムな報酬（宝箱）** | Duolingo の宝箱、各種ゲーム | 中身が予想できないと期待感（ドーパミン）が生まれ、飽きにくい | 子どもは変動報酬に影響されやすい。**お金と結びつけない・あと少しで外れる演出（ニアミス）を使わない**ことが大事 |
| **収集・図鑑のコンプリート** | ポケモン図鑑、カード | 完成に近づくほど続けたくなる「完成バイアス」。持っている物に愛着がわく（保有効果） | 何が足りないかが見えること（進捗の可視化）が重要 |
| **シーズン（バトルパス型）の段階報酬** | フォートナイト等 | 毎月・毎シーズンの「ゴール」と限定報酬が、続ける理由になる | 子ども向けでは**課金なし・期限の焦りを強くあおらない**。カウントダウン表示は不安を生むという指摘あり |
| **相棒キャラ（育てる・話しかける）** | Finch（自分のケアで小鳥が育つ） | キャラへの愛着が「この子のためにやろう」という気持ちを生む | タスクとキャラの成長がつながっていないと飽きられる（Habitica のレビューより） |
| **リーグ・ランキング** | Duolingo リーグ | 競争と昇格の楽しさ | サーバーが必要。子どもの個人情報・比較による落ちこみに注意 → **今回は見送り** |
| **ふりかえり（まとめ）** | Spotify の年間まとめ等 | 自分の頑張りが数字で見えると達成感が強まる | — |
| **演出（ジュース）** | 紙吹雪・効果音・振動 | 達成の瞬間の気持ちよさが「またやりたい」につながる | 動きが苦手な人向けに「動きを減らす」設定に対応 |

## 2. れんしゅうクエストに入れたもの

すべて **お金なし・練習した分だけ報われる** 形にしています。

1. **お守り（ストリークフリーズ）** 🧿
   - 1日練習しなくても、お守りが自動で連続記録を守る（相棒が教えてくれる）。
   - 週の目標（週4日）を達成すると +1（最大3個）。
   - 「休むのも練習」というスポーツ科学の考え方とも合う。
2. **宝箱** 🎁
   - 練習の合計60分ごとに必ず1個もらえる（運だけで決まらない）。
   - 中身はコイン（30〜150）か、宝箱でしか手に入らないレアアイテム（レインボーボール・クリスタルスパイク・レジェンドユニフォーム・オーロラ背景）。
   - ハズレは無し（必ずコインがもらえる）。ニアミス演出は無し。
3. **月間チャレンジロード** 🛣️（バトルパス型・無料）
   - 毎月、練習でためたEXPで10段階進む。報酬はコイン、5段目は宝箱、ゴールは**その月だけの限定背景**（お正月・さくら・花火・もみじ・クリスマス…12種類）。
   - 月ごとの限定背景がコレクションになる。残り日数は小さく表示するだけ（焦らせない）。
4. **相棒キャラ「ボルト」** ⚽
   - ホームで、状況に合わせて話しかける（クエスト案内、HPが少ないときは休もう、連続記録をほめる、宝箱のお知らせなど）。タップで次のセリフ。
5. **先週のふりかえり** 📊
   - 週のはじめにアプリを開くと、先週の練習日数・分数・EXP・自己ベストをまとめて表示。
6. **コレクション率と称号の進捗バー** 📚
   - スキル画面の一番上に、称号・スキル・カード・アイテムの集めた割合（％）。
   - まだ取っていない称号に「あとどれくらいか」の進捗バー。
7. **演出の強化** 🎉
   - レベルアップ時の紙吹雪、効果音（ファンファーレ）、スマホの振動。「せってい」でオフにできる。

## 3. 今回は入れなかったもの（理由）

- **リーグ・ランキング**：サーバーと個人情報の管理が必要。チーム機能を作るときに、保護者・コーチの管理つきで検討。
- **ガチャ（課金）・有料アイテム**：子ども向けアプリでは審査・倫理の両面で避ける。
- **毎日ログインするだけのボーナス**：「練習せずに開くだけ」を報酬にすると目的からずれるため、練習と結びついた報酬だけにした。
