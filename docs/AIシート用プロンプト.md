# AIで「1枚に10パターン」作るためのプロンプト集

ChatGPT などの画像生成AIに、**1枚の画像に複数のイラストを格子状に並べて**作ってもらうためのプロンプトです。
できた画像は **`tools/sheet-cutter.html`**（ブラウザで開くだけ）で1つずつのPNGに切り分けられます。

## うまくいくコツ
- **「5列×2行の格子」「各マスの中央に1つ」「重ならない」「同じ大きさ」**をはっきり書く。
- 背景は**単色のグレー（#E5E5E5）**にしてもらう。白いボールや黒いスパイクとも区別でき、切り出しツールで透明にしやすい。
- 文字・ロゴ・番号・枠線は**入れない**（切り出すときに邪魔になる）。
- 気に入ったものが見つかったら、それだけを**1枚で大きく作り直す**と高画質になる。
- 実在のブランド・チーム・企業のロゴ、既存のキャラクターは入れない。
- 使うAIサービスの利用規約で「商用利用OK」かを確認する。

## 切り出しツールの使い方
1. `tools/sheet-cutter.html` をブラウザで開く（ダブルクリックでOK）
2. 画像をドラッグ＆ドロップ
3. 「横の数」「縦の数」をシートに合わせる（5×2 など）。格子がずれていたら「外側の余白」を調整
4. 「ファイル名」に名前を並べる（下の各シートに書いてあるものをコピー）
5. 「切り出す」→「まとめて保存」→ できたPNGを `img/` フォルダに入れる

## 共通スタイル（すべてのプロンプトの先頭に付ける）
```
日本のスポーツアニメ・ゲーム風のかっこいいイラスト。はっきりした線画、メリハリのある影、高級感のあるつや。子ども向けサッカーアプリのアイテム。
画像全体を5列×2行の格子に分け、各マスの中央にイラストを1つずつ、合計10個。すべて同じ大きさ・同じ向き・重ならない。
背景は単色のグレー（#E5E5E5）。文字・ロゴ・番号・枠線は入れない。
```

## ① ボール 10種類（5列×2行）
```
（共通スタイル）
サッカーボールを10種類。ななめ上から見た立体的な見た目。
1 クラシックな白黒 / 2 赤と白 / 3 蛍光イエローのネオン / 4 青い炎をまとった / 5 オレンジの炎をまとった /
6 金色にかがやく / 7 虹色 / 8 夜空と星の柄 / 9 雷の柄 / 10 氷のクリスタル
```
ファイル名：`ball-1,ball-2,ball-3,ball-4,ball-5,ball-6,ball-7,ball-8,ball-9,ball-10`

## ④ キャラクターのアイデア出し 10人（5列×2行）
```
（共通スタイル。ただし「アイテム」を「キャラクター」に読みかえる）
小学生くらいのサッカー選手のキャラクターを10人。全身、正面やや斜め、立ちポーズ。
少年5人・少女5人。髪型・髪の色・表情・体型をそれぞれ変える。全員おそろいの紺と水色のユニフォーム。
```
ファイル名：`idea-1,idea-2,idea-3,idea-4,idea-5,idea-6,idea-7,idea-8,idea-9,idea-10`
→ 気に入ったキャラを選んで、次の⑤で8ステージを作る

## ⑤ 1人のキャラの成長8ステージ（4列×2行）
**1人を1枚にまとめると、全ステージで顔がそろいやすい。** ④で選んだキャラの画像を添付して、「このキャラクターで」と頼む。
```
（共通スタイル。ただし「5列×2行・10個」を「4列×2行・8個」に読みかえる）
添付したキャラクターと同じ顔・同じ髪型で、サッカー選手として成長していく8つの姿。全身。左上から順に：
1 Tシャツと短パン、ボールを足元に置いて笑顔 / 2 ジャージでリフティング / 3 チームのユニフォームでドリブルの構え / 4 ビブスを着て鋭いドリブル /
5 白い代表ユニフォームでキャプテンマーク / 6 赤い代表ユニフォームでシュートの瞬間 / 7 青いユニフォームで腕組みの決めポーズ、目に青い光 / 8 金のラインの黒いユニフォームで空中ボレー、金色のオーラ
```
ファイル名（アイデア1のキャラの場合）：`idea-1_1,idea-1_2,idea-1_3,idea-1_4,idea-1_5,idea-1_6,idea-1_7,idea-1_8`
→ `img/chars/` に入れると、そのキャラのステージごとの絵に自動で切りかわる

## ⑦ 練習場所の背景 8種類（1枚に1つ・正方形）
練習画面の上で、マイキャラの後ろに大きく出る背景。**人物は入れない**（キャラはアプリが前に重ねる）。
画面の**下3分の1は地面**（キャラが立つ場所）にして、中央はあけておく。1枚に1つずつ作るときれい。
```
アニメ調のサッカーゲームの背景イラスト。人物なし。正方形。明るく、子どもがわくわくする雰囲気。
画面の下3分の1は地面で、中央には何も置かない（あとでキャラクターを重ねるため）。文字・ロゴは入れない。
場所：（下の1〜8のどれか）
```
1 家の庭（芝生と木の柵、家の壁、青空）／2 近所の小さな公園（すべり台と砂の地面、夕方前の空）／3 大きな公園（広い芝生、木々）／
4 河川敷（土手と川、夕焼け、遠くに橋）／5 小学校の土のグラウンド（校舎、鉄棒、白線）／6 人工芝のフットサルコート（ナイター照明、フェンス、夜）／
7 きれいな天然芝のピッチ（ゴール、晴れた青空、芝のしま模様）／8 観客で満員のスタジアム（ナイター照明、光の演出、熱気）
ファイル名：`stage-1`〜`stage-8` → `img/stages/` に入れると自動で表示（カードの背景にも使われる）。
4列×2行の1枚で作った場合は：`python tools/slice_sheet.py シート 4 2 img/stages stage-1,...,stage-8 --raw --size 1024`

## ⑧ 部屋の背景 8種類（だんだん広く・豪華に。1枚に1つ・正方形）
マイページの背景。**人物なし**。アプリが「トロフィー（左の棚）」「メダル（右の棚）」「ポスター（上の中央）」「ボール・スパイク（床の左右）」「キャラ（中央）」を重ねるので、
**左右の壁の上のほうに空の棚**、**上の中央に何も貼っていない壁**、**床の中央はあけておく**。
```
アニメ調のゲームの部屋の背景イラスト。正面から見た部屋。人物なし。正方形。文字・ロゴは入れない。
左の壁と右の壁の上のほうに、何も置いていない棚。上の中央は何も貼っていない壁。床の中央には何も置かない。
部屋：（下の1〜8のどれか）
```
1 せまい物置部屋（段ボール、古い木の床、小さな窓）／2 小さな子ども部屋（学習机、たたみ）／3 サッカー好きの部屋（青い壁、ボールかご）／
4 広めの自分の部屋（ベッド、大きな窓）／5 トロフィールーム（ガラスケース、スポットライト）／6 選手寮の広い部屋（ソファ、大型テレビ）／
7 高層マンションの部屋（夜景の大きな窓、モダンな家具）／8 豪邸の殿堂ルーム（シャンデリア、金の装飾、赤いじゅうたん）
ファイル名：`room-1`〜`room-8` → `img/room/` に入れると自動で表示。

## できた画像をアプリに入れたら
- キャラのステージ別の絵 `idea-番号_1`〜`idea-番号_8` は `img/chars/` に、練習場所 `stage-1`〜`8` は `img/stages/` に、部屋 `room-1`〜`8` は `img/room/` に入れるだけで自動で表示される（切り出しと配置はClaudeに頼めばOK）。
- ボール・スパイク・ユニフォーム・ボルトの画像は、画像を入れてもらえれば、アプリのショップ・着せ替え・ホームで使えるように組み込む。
