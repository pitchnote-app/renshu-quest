# ストア掲載文（案）

## アプリ名
れんしゅうクエスト

## サブタイトル（30文字以内）
練習するほど強くなる！サッカー育成アプリ

## 短い説明（Google Play・80文字以内）
サッカーの練習を記録すると、自分の選手がレベルアップ。毎日の自主練が楽しくなる！

## 説明文

**練習すればするほど、自分の選手が強くなる。**
れんしゅうクエストは、子どもたちが「自分から」練習したくなるサッカー育成アプリです。

■ 練習を記録して、選手を育てよう
リフティング、ドリブル、ダッシュ、体幹トレーニング…。練習を記録すると経験値がたまり、レベルアップ！ スピード・アジリティ・ボールタッチなど9つの能力が伸びていきます。

■ おうちの庭から、ワールドクラスへ
レベルが上がると、選手カードが進化。「おうちの庭」から「公園」「チーム入団」「トレセン」「県代表」「日本代表」…そして「ワールドクラス」を目指そう。

■ 52種類の練習メニュー（図解つき）
足裏コロコロ、インアウト、クライフターン、8の字ドリブル、壁パス、ラダー、プランク…。定番の自主練メニューを、わかりやすいイラストとやり方つきで紹介。

■ 毎日のクエストと、週替わりのライバル
今日のクエストをクリアしたり、自己ベストを超えて「ライバル」を倒したり。ゲーム感覚で目標に挑戦できます。

■ スポーツ科学にもとづく成長
年齢によって伸びやすい能力（ゴールデンエイジ）を「のびどき」で表示。練習しすぎを防ぐHP（疲れ）の仕組みや、休養日のボーナスで、ケガをしにくい練習習慣を応援します。

■ 職業・スキル・称号
フォワード、ミッドフィルダーなどの職業に転職。条件を満たすと「ファンタジスタ」などの上級職に！ 技（スキル）や称号もどんどん増えていきます。

■ キャラメイクと着せ替え
髪型・目・ユニフォームまで、自分だけの選手を作れます。練習でためたコインで、ボールやスパイク、背景と交換しよう。

■ 保護者の方へ
・広告なし、課金なし
・記録は端末の中だけに保存され、外部に送信されません
・データの削除などの操作には保護者の確認があります
・カレンダーで練習の継続が一目でわかります
