# れんしゅうクエスト　公式アプリ化までの手順

最終目標：App Store（iPhone）と Google Play（Android）から無料でダウンロードできる公式アプリにする。

## 全体の流れ

| # | ステップ | 状態 | 必要なもの・費用 |
|---|---|---|---|
| 1 | Webアプリとして完成させる（今のアプリ） | **進行中** | なし |
| 2 | PWA化（ホーム画面アイコン・オフライン起動） | **済** | なし |
| 3 | ネットに公開して家族・チームで試す（ベータ） | 未 | 無料のホスティング（例：GitHub Pages、Cloudflare Pages、Netlify） |
| 4 | アプリの「ガワ」に包む（Capacitor） | 未 | Node.js（PCに入っていることを確認済み） |
| 5 | Android版を作って Google Play に出す | 未 | Google Play デベロッパー登録（1回 25ドル）、Android Studio |
| 6 | iPhone版を作って App Store に出す | 未 | Apple Developer Program（年 99ドル）、**Mac が必要**（またはクラウドビルド） |
| 7 | 公開後の運用（アップデート・お問い合わせ対応） | 未 | サポート用メールアドレス、Webページ |

> 費用がかかる手続き・アカウント作成・公開は、オーナーの判断で行ってください（このメモはその準備用です）。

## ステップ3：ベータ公開（おすすめの次の一手）
- フォルダ一式（`index.html`, `app.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icons/`）をそのままアップロードすれば動く。
- HTTPS で公開されると、スマホで「ホーム画面に追加」→ オフラインでも起動できる。
- 子どもやチームメイトに使ってもらい、感想を集める（どこで迷ったか、何が楽しかったか）。

## ステップ4：Capacitor でネイティブアプリ化
```
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
npx cap init "れんしゅうクエスト" jp.example.renshuquest --web-dir www
（index.html などを www/ に入れる）
npx cap add android
npx cap add ios
npx cap sync
```
- アプリID（`jp.example.renshuquest` の部分）は、独自ドメインを逆にしたものにする（例：`jp.co.会社名.renshuquest`）。一度決めると変えられない。
- ネイティブ化すると使えるようになるもの：
  - **練習リマインダー通知**（@capacitor/local-notifications）
  - **データの端末保存を強化**（@capacitor/preferences。ブラウザのデータ消去で消えない）
  - **振動（ハプティクス）**でレベルアップ演出を強化

## ステップ5・6：ストア申請で必要なもの
- [ ] アプリ名・サブタイトル・説明文 → `docs/ストア掲載文（案）.md`
- [ ] プライバシーポリシーのURL → `docs/プライバシーポリシー（案）.md` をWebに公開
- [ ] サポートURL（お問い合わせページ）
- [ ] スクリーンショット（iPhone 6.7インチ／6.5インチ、Android スマホ）各3〜8枚
- [ ] アプリアイコン 1024×1024（`tools/make_icons.py` のサイズを変えれば作れる）
- [ ] 年齢区分の質問への回答（暴力・課金・広告などなし → 4+／全年齢の見込み）
- [ ] 「データの安全性」（Google）・「App のプライバシー」（Apple）の回答：**データを収集しない**

## 子ども向けアプリとして注意すること（審査で見られる点）
Apple の「キッズ」カテゴリや Google の「ファミリー向け」ポリシーに合わせる。
- [x] **広告なし・外部の解析ツールなし**（今のアプリは入っていない）
- [x] **個人情報を外部に送らない**（記録は端末内のみ）
- [x] **保護者確認（ペアレンタルゲート）**：データ削除・バックアップ・読みこみの前に、かけ算の問題を出している。今後、外部リンクや課金を入れる場合も必ずこの後ろに置く。
- [x] **フォントをアプリに同梱**（Noto Sans JP・Dela Gothic One。SIL Open Font License。`fonts/` にライセンス文も同梱）→ 外部との通信はゼロ
- [ ] 課金を入れる場合は「保護者の確認」＋「わかりやすい表示」が必須。最初は**完全無料・課金なし**が審査も通りやすい。

## 名前・権利まわりのチェック
- [ ] アプリ名「れんしゅうクエスト」が他のアプリや商標とかぶっていないか、ストアと特許庁の「J-PlatPat」で検索する。
- [ ] 「ドラクエ」「ドラゴンクエスト」などの他社の作品名は、アプリ名・説明文・画像に使わない（宿屋・転職・呪文などの一般的な言葉はOK）。
- [ ] ブルーロック・ワンピースカードなど、参考にした作品の名前やキャラクターも使わない。
- [ ] 練習メニューの名前（クライフターン等）は一般的なサッカー用語なので問題なし。
- [ ] AIで作ったイラストを使う場合は、そのAIサービスの利用規約で「商用利用可」かを確認する。

## 今後の機能アイデア（優先度順）
1. **練習リマインダー通知**（ネイティブ化後）
2. **保護者モードの強化**：保護者が練習を「確認済み」にできる（自己申告の信頼性アップ）
3. **チーム機能・ランキング**：コーチや友達と記録を比べる（サーバーが必要。子どもの個人情報の扱いに注意）
4. **練習メニューの動画**：自分たちで撮った手本動画を入れる（他人のYouTube動画の埋めこみは権利と外部リンクの問題があるので注意）
5. **他のスポーツ版**（野球・バスケなど）：`app.js` の能力・メニュー定義を差し替えて作れる構造にしてある
